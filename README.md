# Intelligent Illumination

A smart AIoT system that uses YOLO and Arduino for real-time human detection and intelligent lighting control.

## 🧠 Tech Stack
- YOLO (Object Detection)
- OpenCV (Camera Feed Processing)
- Arduino + Relays (Hardware Control)
- Python (Control Scripts)

## 📸 How It Works
1. YOLO detects humans in real-time video feed.
2. If humans are detected, the system activates room lights.
3. Arduino handles relay switching based on detection signals.
